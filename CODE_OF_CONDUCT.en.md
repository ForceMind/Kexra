# Kexra Code of Conduct

We expect professional, respectful and evidence-based collaboration. Harassment, threats, discrimination, leaking private information and misuse of another person's infrastructure are not acceptable.

Do not encourage unauthorized security testing, expose secrets in issues, fabricate test evidence or misrepresent third-party code as wholly original. Preserve the license and copyright notices required by the incorporated open-source code.

Maintainers may request edits, remove inappropriate content or restrict participation as permitted by the platform. Sensitive security concerns belong in a private reporting channel described in [SECURITY.md](SECURITY.md), not public comments.

The primary maintained version is the [Chinese community policy](CODE_OF_CONDUCT.md).
