# Kexra 开发路线

工作入口：[当前状态与交接](WORK_STATUS.md)；发布结论以 [验收清单](RELEASE_CHECKLIST.md) 为准。所有任务只面向自有资产、授权环境或隔离实验室。

## 状态约定

- **已完成并验证**：有明确提交范围及实际测试证据。
- **已实现但未验证**：代码存在，缺少对应环境的运行证据。
- **开发中**：正在修改和验证，尚不能作为主线能力宣称。
- **阻塞**：缺少环境、权限或发布决策，记录恢复条件。
- **计划中**：尚未实施。
