# Kexra 发布验收清单

当前结论：**不可正式发布**。历史验收见 [迁移记录](MIGRATION.md)；当前改动的实测结果见 [工作状态](WORK_STATUS.md)。勾选必须有对应候选提交及证据，历史成功不自动转移到新版本。

## 候选提交与质量

- [ ] 固定候选 SHA、版本号、支持平台及回退提交，确认分支包含最新主线。
- [ ] Go 全仓库 build、vet、非数据库单测；说明所有跳过项。
- [ ] PostgreSQL 16 六模块隔离集成测试。
- [ ] `npm ci`、Biome、Web 静态构建、中文资源与运行时关键流程。
- [ ] 更名契约、内部文档链接、合成检测规则回归。

## 供应链与权限

- [ ] 审查 Go 与 npm 锁定依赖，处理高危/严重漏洞并保存扫描失败或豁免原因。
- [ ] 基础镜像、Node、工具传递依赖、浏览器、apt 的实际清单与漏洞报告。
- [ ] 生成真实二进制/镜像 SBOM、依赖许可记录及 SHA256 清单；保留 AGPL/MIT/来源信息。
- [ ] 认证、授权、工具调用、文件与出站网络边界通过隔离验证。
- [ ] 密钥与历史提交审计；不提交真实配置、JWT 或客户数据。

## 安装与升级

- [ ] 五平台发布包布局、版本、可执行文件、校验文件；交叉编译和原生运行分别记录。
- [ ] Linux amd64/arm64 镜像真实构建和运行；管理与代理默认本机监听。
- [ ] 新安装、管理员初始化、旧用户名/Cookie、重启后 JWT 和数据保持。
- [ ] 旧实例数据、JWT、Skills 备份，以及数据库副本恢复与配置兼容。
- [ ] 模拟 Release 下载、校验、暂存、换装、成功确认、连续失败自动回滚及手动回滚。
- [ ] Docker 使用镜像升级/回退；容器可写层二进制替换不能作为持久升级证明。

## 正式发布操作前

- [ ] 发布主体、源码提供义务、目标镜像命名空间及发布权限已确认。
- [ ] 候选提交全部验收结束；风险与回退方式可审查。
- [ ] 正式发布/镜像推送与生产迁移作为独立动作审慎确认，不以开发授权替代未完成验收。

六套正式工作流保持手动。不得为演练创建正式 `v*` 标签或将服务开放到公网。
